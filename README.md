# Gestion des Assets

Ce dossier contient tous les assets statiques utilisés dans l'application.

## Structure des dossiers

- `/images` : Images et icônes
- `/models` : Modèles 3D et animations
- `/data` : Fichiers de données statiques

## Bonnes pratiques

- Utilisez des noms de fichiers descriptifs et en minuscules
- Optimisez les images avant de les ajouter
- Documentez les sources des assets externes
- Respectez les formats recommandés :
  - Images : SVG, WebP, PNG
  - Modèles 3D : GLTF/GLB
  - Données : JSON
